# 서운픽 — 서운중 학생 투표

서운중학교 학생들이 먹고 싶은 급식 메뉴 또는 학교에 바라는 의견을 한 줄로 올리고 투표하는 공개 웹 앱입니다.

## 주요 기능

- 메뉴 이름 또는 의견 한 줄만으로 빠른 등록
- 학생 의견 TOP 5 자동 순위
- 급식 메뉴 1위 자동 표시
- 급식 투표와 학생 의견 투표 분리
- 먹고 싶어요 / 별로예요 투표
- 공개 댓글과 링크 공유
- 작성자 본인의 제안 삭제
- 여러 브라우저에서 공유되는 분산형 실시간 데이터

정적 HTML/CSS/JavaScript로 구성되어 GitHub Pages에서 바로 실행됩니다.

서운중학교 로고는 [서운중학교 공식 홈페이지](https://seoun.sen.ms.kr/)에 공개된 학교 로고를 사용했습니다.
