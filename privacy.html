1. 수집하는 정보

급식픽은 회원가입을 요구하지 않습니다. 사용자가 메뉴 제안이나 댓글을 올릴 때 입력한 표시 이름과 게시 내용, 브라우저에서 자동 생성된 익명 공개키가 공개 네트워크에 저장됩니다. 서비스 운영을 위해 접속 과정에서 일반적인 기술 정보가 호스팅·중계 서비스에 의해 처리될 수 있습니다.

2. 이용 목적

입력 정보는 메뉴 제안, 투표, 댓글 표시와 작성자 본인의 게시물 관리 기능을 제공하기 위해 사용됩니다.

3. 공유와 보관

게시물과 투표는 누구나 접근할 수 있는 분산형 중계 서버를 통해 공유되므로 공개 정보입니다. 민감한 개인정보를 입력하지 마세요. 삭제 요청은 네트워크에 전달되지만, 공개 네트워크의 특성상 이미 복제된 정보가 모든 외부 서버에서 즉시 사라지는 것은 보장할 수 없습니다.

4. 기기 저장 정보

브라우저의 로컬 저장소에 익명 서명키와 표시 이름을 저장하여 투표 중복을 줄이고, 본인 게시물을 관리할 수 있게 합니다. 브라우저 데이터를 삭제하면 기존 작성자 권한을 복구하지 못할 수 있습니다.
